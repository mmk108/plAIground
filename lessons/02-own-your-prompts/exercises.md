# Exercises

1. **Read the diff.** Compare `v1_vague.md` and `v2_clear.md`. List every difference, then guess which one fixes which failing case.
2. **Write v3.** Copy `v2_clear.md` to `v3_yours.md`, improve it, and re-run the comparison.
3. **Add 5 eval cases** from your own real requests, including ones that should be refused.
4. **Make it yours.** Change the assistant's tone (formal, friendly) in the prompt. Does accuracy change?
5. **Track it.** Commit each prompt version with a message describing what changed and the score.
